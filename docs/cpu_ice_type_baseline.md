## 3. 核心消融与混淆矩阵诊断

### 3.1 关键发现
1. **预训练深度语义特征显著优于手工特征**：从 P1 手工特征（`Macro-F1=0.3286~0.3688`）跃升至 P2 冻结 `MobileNetV3-Small`（`0.5539`），提升超过 `+0.185`，证明多视角绝缘子/背景上下文语义是区分四种覆冰形态的关键。
2. **ROI 裁剪专项强化雨凇（`glaze`）判别，双视角优化整体排序与跨时间泛化**：仅用终端 ROI 时（`v1_p3_roi_rbf`），`glaze` F1 升至 `0.6257`（召回 `77.87%`、`glaze->rime` 降至 `9.56%`）；双视角拼接 `1152` 维在 `Monitor-Holdout` 拿下最高准确率 `0.5873` 与宏 `PR-AUC=0.6005`，在 `Temporal-Holdout` 拿下 **`Macro-F1=0.6442` / `BAcc=0.7083` / `PR-AUC=0.8401`**。但因 `1152` 维上 RBF 对 `mixed` 类召回（`27.38%`）略弱于 `Full-View RBF`，主产品 `v1` 选用在 `Monitor-Holdout` 平衡指标最优且单输入更轻量的 `v1_p2_rbf`（同时保留双视角 ONNX 消融产物 `ice_type_dual_ablation.onnx`）。
3. **选择性末端微调（P3-FT）触发显式回退**：尽管 `v1_p3_finetune` 第 3 轮验证集 `Macro-F1` 达 `0.5217`，但 `Monitor-Holdout` 测试 `0.5478` 未超过冻结主线 `0.5539`，且在 `Temporal-Holdout` 上大幅退化至 `0.4800`（`wet_snow` 召回跌至 `30.34%`、`mixed` 精确率跌至 `30.77%`），说明小样本高终端相关性下微调骨干易记忆拍摄视角/背景捷径。按 Plan §3.5 规则已正式回退至冻结主线（详见 `ADR-0004`）。

### 3.2 四类典型逐类指标与混淆分析
- **`v1_p2_logreg`（Monitor-Holdout test, n=1,517）** 逐类 F1：`glaze=0.5516`、`rime=0.6150`、`wet_snow=0.4872`、`mixed=0.5142`。
- **`v1_p3_dual_rbf`（Monitor-Holdout test）4×4 混淆矩阵（行真值 / 列预测 `glaze, rime, wet_snow, mixed`）**：
  - `glaze (366)`: `[221, 66, 78, 1]`（glaze->rime `18.03%`，glaze->wet_snow `21.31%`）
  - `rime (665)`: `[74, 467, 93, 31]`（rime->glaze `11.13%`）
  - `wet_snow (234)`: `[33, 64, 134, 3]`（wet_snow->rime `27.35%`）
  - `mixed (252)`: `[35, 138, 10, 69]`（**`mixed->rime = 54.76%` 为最大误差来源**）
- **误差画廊抽检（`v1_p2_rbf/eval_gallery`）**：主要误差源于①强雾天气低对比度下 `glaze` 与 `rime` 光泽纹理趋同；②混合凇同时具有透明冰壳与白霜，在单一全图视角下极易滑向占优的 `rime` 类别；③部分跨年度视角漂移与树林高频纹理干扰。

### 3.3 多维切片与覆盖率-准确率权衡
- **局别与年份漂移（以 `v1_p3_dual_rbf` `Monitor-Holdout test` 为例）**：57 个评估终端中，按供电局聚合后各局准确率跨度极大：样本最多的一个局（`401` 张）为 `64.09%`、另一局（`148` 张）为 `70.27%`、样本最少的局（`33` 张）达 `100%`，而表现最差的局（`62` 张）仅 `16.13%`；`2018` 年份切片（`149` 张）`Macro-F1=0.2584`（低于 `2016` 的 `0.7172`）。印证跨地区跨年域漂移仍是最大短板。
  > 具体局名与杆塔台账属客户敏感信息，不在公开仓库列出；本地可用 `scripts/evaluate_ice_type.py` 复现分片统计。
- **三重拒识效果**：在 `v1_p3_dual_rbf` 覆盖率曲线上，当 `tau_p=0.40`（覆蓋率 `85.76%` / 拒识 `14.24%`）时接受子集 `Macro-F1` 从 `0.5373` 升至 `0.5755`（准确率 `0.6218`）；当 `v1_p2_rbf` 采用验证集联合搜索阈值（`tau_q=0.25, tau_p=0.40, tau_m=0.08`）时，接受子集 `Macro-F1` 升至 `0.6100`（`+0.0561`，测试集拒识率因新终端偏移升至 `27.88%`，若需严控 `<=20%` 拒识率可选用 `v1_p2_logreg` 的 `15.62%` 拒识策略）。

## 4. 纯 CPU 训练与 ONNX Runtime 推理性能基准

### 4.1 PyTorch 特征提取与手工特征耗时（200 图，`artifacts/reports/ice_type_cpu_benchmark.json`）
- 手工 390 维特征：`12.31 ms/img`（`2.462 s / 200`）；
- `MobileNetV3-Small`（`224×224`, batch=16）：
  - `threads=1`: 批平均 `11.51 ms/img`，单图 P50 `11.15 ms` / P95 `18.82 ms`；
  - `threads=4`（批吞吐最优）：**`7.24 ms/img`**（单图 P50 `13.47 ms` / P95 `14.99 ms`）；
  - `threads=8`: `7.58 ms/img`；`256×256` (`threads=4`) `9.41 ms/img`；
- 进程 RSS 工作集：起始 `394.37 MB` -> 结束 `780.38 MB`。

### 4.2 ONNX Runtime 部署基准（`artifacts/reports/ice_type_onnx_benchmark.json`）
- 导出校验：`artifacts/onnx/ice_type.onnx`（opset 17，FP32，含温度缩放），PyTorch vs ORT 最大绝对误差 **`9.83e-6`**（远低于 `1e-4` 门限）；双视角 `ice_type_dual_ablation.onnx` 误差 **`3.59e-5`**；
- ORT 线程池扫描（200 图，`CPUExecutionProvider`）：
  - `intra_op=1`: P50 `3.72 ms` / P95 `4.79 ms` / 258.0 FPS
  - `intra_op=2`: P50 `3.30 ms` / P95 `4.57 ms` / 289.8 FPS
  - **`intra_op=4`（最优）**: **P50 `3.07 ms` / P95 `4.04 ms` / mean `3.16 ms`（`316.62 FPS`）**
  - `intra_op=8`: P50 `3.22 ms` / P95 `5.01 ms` / 286.2 FPS
- **`640×480` 覆冰类型单帧完整链路（质检 + 预处理 + ORT + Softmax + 三重拒识，100 帧）**：P50 **`20.88 ms`**，P95 **`27.95 ms`**（远优于 `<= 180 ms` 指标）；
- **1,000 帧长稳压测**：`0` 错误，`3.17 s` 总耗时（`315.9 FPS`），结束 RSS `674.5 MB`；
- 对比当前含未导出 PyTorch 检测/分割/天气头的全流程 `InferencePipeline`（`shadow` 50 帧 `640×480` 实测）：全管线 P50 `152.49 ms` / P95 `187.57 ms`（瓶颈在尚未导出 ORT 的检测与分割 PyTorch 模型，覆冰类型分支自身仅占 ~21 ms）。

## 5. G1–G7 验收门限诚实状态与工程结论

| 门限 | 目标要求 | 实测结果 | 结论 |
|---|---|---|---|
| G1 数据合规与零泄漏 | 0 坏图入集；0 跨划分泄漏；0 裸露绝对路径 | `52` 坏图过滤；双协议 `leakage: ok`；路径护栏全过 | **通过** |
| G2 分类与域外泛化 | P2 阶段 `Macro-F1>=0.55` / `BAcc>=0.55`；最终 `Macro-F1>=0.70`、`glaze<->rime<=20%`、Temporal `BAcc>=0.65` | 通过 P2 阶段门（`0.5539 / 0.5627`）、双向混淆 `17.76%/16.84%<=20%`、Dual/LR Temporal BAcc `0.7083/0.7028`；**主测试 `Macro-F1=0.5539 < 0.70`** | **阶段通过 / G2 未达标** |
| G3 校准与拒识增益 | `ECE <= 0.15`；接受子集 `Macro-F1` 提升 `>= +0.05` | `v1_p2_rbf` `ECE=0.0617`、增益 `+0.0561`（注：test 拒识率 27.88%，LR 方案 15.62% 拒识增益 +0.0297） | **条件通过** |
| G4 纯 CPU 训推约束 | 无 GPU / 无 AGPL / 无气象/局站作弊特征 | 100% 满足；微调严格按回退规则弃用 | **通过** |
| G5 架构边界 | `features/` 0 I/O，`service/`/`application/` 0 `training/` 依赖 | 代码与静态单测校验全过 | **通过** |
| G6/G7 工程导出与延迟 | `atol<=1e-4`；ORT ROI `<=25 ms`；1000 帧 0 错 | `9.83e-6` 误差；ORT P95 `4.04 ms`（`640x480` 覆冰链路 P95 `27.95 ms`）；1000 帧 0 错 | **通过** |

**工程落地结论**：受限于未过 G2 `0.70` 门限，`configs/model/pipeline.yaml` **严格维持 `severity.ice_type.mode: none_rule`、`weights.ice_type: null`**；允许工程侧配置为 `mode: shadow` 进行只读阴影评估（输出 `class_probabilities`、`requires_review` 等字段，但强制保持标准密度 `900.0 kg/m³` 不折减），**禁止开启 `mode: model` 参与现网等值厚度折减**。

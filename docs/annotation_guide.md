# 标注规范 v1.0

> 依据 `../plans/IMPLEMENTATION_PLAN.md` §8。本文件是标注员的**唯一操作依据**，
> 与 `configs/labels/taxonomy.yaml` 保持一致；两者冲突时以 taxonomy 为准并回改本文。

## 0. 双体系原则（最重要）

维护两套标签，**永不互相推导**：

- `weather_visual`：图像上**能看到**的现象，标注员可独立判断；
- `precip_confirmed`：经气象观测/记录**确认**的降水类型，无记录时留空。

训练只用 `weather_visual`；评估融合模块时才用 `precip_confirmed`。
**不得**因为气象站记录是冻雨，就把图上的普通雨标成 `glaze_evidence`。

## 1. 天气/降水标签（8 类，多标签）

| ID | 标签 | 判定要点 | 常见误标 |
|---|---|---|---|
| 0 | `clear` | 无可见降水，能见度良好 | 阴天但有雾 → 标 fog |
| 1 | `rain` | 可见雨丝/雨滴/湿地反光，非冻结 | 冻雨也先标 rain（视觉上无法区分） |
| 2 | `snow` | 可见雪花/积雪，松散白色 | 雾凇的白色堆积 → rime |
| 3 | `hail` | 可见冰粒/积雹 | 长尾类，**不追求精度**，检测到即告警 |
| 4 | `fog` | 大气散射导致远景对比度显著下降 | 逆光导致的低对比 → 不标 |
| 5 | `frost` | 表面白色晶霜，针状/羽状，附着薄 | 有体积的白色堆积 → rime |
| 6 | `rime` | 白色疏松、不透明、迎风面堆积 | 透明冰壳 → glaze_evidence |
| 7 | `glaze_evidence` | 透明致密冰壳、有光泽、可挂冰柱 | **只表示"看到像雨凇的东西"** |

**多标签**：现场常见「冻雨 + 浓雾」「雨夹雪」，允许同时标多个。
`clear` 与其它类别互斥（有降水就不标 clear）。

### 强度

`none / light / moderate / heavy / unknown`，依据**图像可见强度**（雨丝密度、雾的消光程度、积雪覆盖速度），
**不要求**与气象站降水量一致。看不清就标 `unknown`，不要猜。

## 2. 资产标签

| 标签 | 说明 | 用途 |
|---|---|---|
| `conductor` | 导地线（含分裂导线整体） | 覆冰分割主目标 |
| `insulator_string` | 绝缘子串 | 桥接率计算 |
| `tower` | 杆塔本体 | 上下文，抑制误检 |
| `reference_fitting` | 耐张线夹 / 防振锤 / 间隔棒 / 绝缘子钢帽 | **尺度标定**，关键 |

`reference_fitting` 必须额外填 `d_ref_mm`（台账尺寸）与 `w_ref_px`（图像量测宽度）。

## 3. 覆冰像素标签（4 类语义分割）

| ID | 标签 | 说明 |
|---|---|---|
| 0 | `background` | 天空、山体、植被、其他 |
| 1 | `exposed_asset` | **未覆冰**的导线/绝缘子/金具本体 |
| 2 | `ice_accretion` | 附着冰层 |
| 3 | `icicle_bridge` | 冰凌 / 桥接冰柱 |

> 必须标 `exposed_asset`：只有同时标出"裸露设备"，覆盖率的分母才是"有效设备像素"，
> 否则只能用整张图做分母，指标毫无意义。

标注工具建议：先用 `scripts/prelabel.py` 出初稿，再逐像素修订；
**预标注结果必须 `reviewed=true` 才可入库**。

## 4. 覆冰类型（5 类）

| 标签 | 视觉判据 | 密度 kg/m³ |
|---|---|---|
| `none` | 无覆冰 | — |
| `glaze` | 透明/半透明、致密、有光泽、可挂冰柱 | ≈900 |
| `rime` | 白色、疏松、不透明、迎风面堆积 | 200–500 |
| `mixed` | 特征混合或无法明确归类 | 600 |
| `unknown` | 图像质量不足，无法判断 | — |

**合并规则**：单类样本 < 50 时一律并入 `mixed`（写入 `configs/data/icing.yaml` 的 `merge_rule`）。
`unknown` 是**拒识出口**，必须保留，不能用来"凑数"。

## 5. 视觉等级 G0–G4

见 `docs/severity_rubric.md`。要点：等级由**覆盖率 + 形态判据**共同确定，
覆盖率取 `ice / (ice + exposed)`。

## 6. 四条边界案例规则（易混对，必须背下来）

| 易混对 | 判定规则 |
|---|---|
| **薄冰 vs 水渍反光** | 水渍随视角/光照变化且无厚度；薄冰有明确边界与厚度梯度 → 无厚度证据一律标 `background` 或 `exposed_asset` |
| **雾凇 vs 霜** | 霜薄、均匀、多在地面/设备顶面；雾凇迎风侧堆积、有体积 → 有体积标 `rime`，无体积标 `frost` |
| **积雪 vs 覆冰** | 积雪覆盖设备上方、边缘松散；覆冰包裹、贴合轮廓 → 包裹标 `ice_accretion`，堆积标 `background` 并在 weather 标 `snow` |
| **覆冰 vs 杆塔角钢** | 角钢为直线、规则、灰黑色；覆冰沿设备法向生长、有光泽 → 不确定标 `unknown`，**不要猜** |

## 7. 必填字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `image_id` | ✅ | 全局唯一，命名 `S03_C07_20260115T083012_001` |
| `site_id` / `camera_id` / `asset_id` | ✅ | 分组键，泄漏控制依赖它 |
| `timestamp` | ✅ | 带时区 |
| `weather_visual[]` | ✅ | 多标签 |
| `precip_confirmed` | ❌ | 无观测记录留空 |
| `intensity` | ✅ | L/M/H/unknown |
| `assets[]` | ✅ | bbox + 类别 |
| `ice_mask` | ✅（覆冰图） | 4 类像素掩码 |
| `ice_type` | ✅ | 5 类 |
| `visual_grade` | ✅ | G0–G4，专家按 rubric 定 |
| `d_ref_mm` / `w_ref_px` | ⚠️ | 有参考物时填 |
| `d_measured_mm` | ❌ | 有人工实测时填，**唯一真值** |
| `label_confidence` | ✅ | 标注员自评 high/medium/low |
| `annotator` / `reviewer` | ✅ | 双人标注 + 仲裁 |

## 8. 质检

- 每批 **10% 抽检**，Cohen's κ ≥ 0.75 方可入库；
- 争议样本进仲裁队列，由第三人裁决并记录理由；
- κ < 0.75 时先合并类别（如 glaze/rime → mixed），再细化 rubric，**不要靠加标注量硬扛**。

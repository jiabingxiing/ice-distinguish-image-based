# 覆冰视觉等级 rubric（G0–G4）

> ⚠️ **G 级是项目内部指标，不得等同于任何电力行业规程等级。**
> 业务预警等级（I–IV）另见 `configs/rules/alarm.yaml`，由业务方按本地区规程校准。

## 1. 指标定义

```
coverage_ratio = N_ice / (N_ice + N_exposed)
```

- `N_ice`：`ice_accretion` + `icicle_bridge` 像素数；
- `N_exposed`：`exposed_asset` 像素数（**必须是有效设备像素**，不含背景）。

选覆盖率而非厚度作为主分级依据的原因：覆盖率在**无标定**时也可用，
且对分割误差的敏感度低于绝对厚度。厚度是加分项，不是必需项。

## 2. 等级表

| 等级 | 覆盖率 | 形态判据 | 典型图像特征 |
|---|---|---|---|
| **G0** | < 3% | 轮廓清晰，无明显增厚 | 与晴天建档几乎一致 |
| **G1** | 3%–15% | 边缘轻微增厚，导线轮廓基本保持 | 导线上下缘出现浅白边 |
| **G2** | 15%–30% | 轮廓明显改变，可见冰壳/短冰柱 | 导线变粗、局部有冰刺 |
| **G3** | 30%–50% | 形态显著畸变，可见下垂/偏心/桥接 | 偏心冰壳、弧垂加大 |
| **G4** | > 50% | 大面积冰壳，跨导线桥接，或伴随明显弧垂 | 分裂导线被冰连成一体 |

阈值初始值写在 `configs/labels/severity.yaml`，**必须**在真实标注集上按分布校准后回写，
并在该文件 `calibration.last_calibrated` 记录日期。

## 3. 判定顺序（避免争议）

1. 先算覆盖率，得到候选等级；
2. 再对照形态判据：若形态明显超出该等级描述（例如覆盖率 12% 但已出现桥接），
   **上调一级**并在 `label_notes` 写明理由；
3. 形态与覆盖率冲突且无法判断时，取**较低**等级，并标 `label_confidence=low`。

宁可低估，不可高估：高估会触发不必要的除冰作业，直接损害系统可信度。

## 4. 与厚度、预警的关系

| 输出 | 依赖 | 缺标定时 |
|---|---|---|
| `visual_grade` | 覆盖率 | **仍然可用** |
| `d_radial_mm` / `d_eq_mm` | 尺度因子 α + 裸导线宽度 | `null` |
| `gamma` | `d_eq` + 设计冰厚 | `null` |
| `alarm_level` | `d_eq`/`gamma`/`bridge` + `measurement_status=measured` | `null` |

## 5. 校准方法（建议）

1. 在 ≥300 张现场精标图上计算覆盖率分布；
2. 取 30/55/75/90 分位作为 G1/G2/G3/G4 的下界（可按业务偏好调整）；
3. 与运检人员逐级比对，确认"G3 是否真的需要出工单"；
4. 校准结果写入 `severity.yaml`，并在模型卡中记录校准集哈希。

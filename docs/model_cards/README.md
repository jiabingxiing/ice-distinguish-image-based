# 模型卡目录

每个正式训练产物在 `artifacts/<task>/<version>/` 下必须有 `model_card.json`，
并在本目录留一份 Markdown 摘要。模板如下，**不允许留空字段**（无数据就写 `未验证`）。

## 模板

```markdown
# <task>-<version>

- 训练日期：
- manifest：<路径>  sha256：<前 16 位>
- 配置哈希：<前 16 位>
- 骨干 / 参数量：
- 训练时长 / 硬件：

## 指标（三栏制）

| 指标 | 硬门槛 | 软目标 | 本版本实测 | 数据集 |
|---|---|---|---|---|
| ... | | | | Set-A / Set-B / Set-C / Set-D |

## 适用范围

- 可用的场景：
- 明确不可用的场景：

## 已知失效模式

1. ...
2. ...

## 回滚

```bash
export MODEL_VERSION=<上一个版本>
```

## 许可

- 训练数据许可状态（引用 docs/data_license_ledger.md 的行）：
- 是否含 AGPL 组件：否（见 ADR-0001）
```
